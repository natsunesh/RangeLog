# RangeLog

**Беспроводной дальномер с журналом измерений и настройкой с ПК.**

RangeLog — учебный проект на Arduino Uno: ультразвуковой дальномер (HC-SR04) с локальной индикацией на LCD 1602, передачей данных по Bluetooth (HC-05) на ПК и записью журнала измерений в SQLite. С ПК можно менять порог тревоги и включать/выключать пищалку; устройство работает автономно и без ПК.

## Стек

- **Микроконтроллер**: Arduino Uno
- **Датчики**: HC-SR04 (расстояние), Tiny RTC DS1307 (время)
- **Индикация**: LCD 1602 + I2C, активная пищалка
- **Связь**: HC-05 (Bluetooth SPP)
- **Питание**: 6×AA (9 В) + тумблер
- **Корпус**: 3D-печать (проектируется с нуля)
- **ПО на ПК**: Go + Wails (десктоп), SQLite, React

## Возможности (текущая версия)

- Измерение расстояния и вывод на LCD (2 режима, переключение кнопкой).
- Иконки статуса на LCD: `BT` (связь), `AL` (тревога), `!` (неисправность датчика).
- Звуковые сигналы: тревога, неисправность, отсутствие/потеря Bluetooth.
- Передача строк `DATA,...` по Bluetooth только при изменении параметров.
- Журнал измерений в SQLite на ПК: дата, время, расстояние, действие, статус.
- Настройка порога и пищалки с ПК, сохранение в EEPROM по команде `save`.
- Автопереподключение ПО при обрыве связи, без дублей в журнале.
